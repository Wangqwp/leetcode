## 🎯 DP解题三步走
1. **定义状态** - dp[i] 代表什么？
2. **写转移方程** - dp[i] 如何由子问题推出？
3. **确定边界** - 初始值是什么？

## 📊 背包DP速查
| 类型 | 内循环顺序 | 特点 |
|------|-----------|------|
| 0/1 背包 | 逆序 | 每个物品只能选一次 |
| 完全背包 | 正序 | 物品可选无限次 |
| 多重背包 | 二进制拆分 | 每个物品有数量限制 |
| 分组背包 | 逆序 | 每组最多选一个 |

## 📊 区间DP速查
- 遍历顺序：区间长度从小到大
- 状态：dp[i][j] = 区间 [i,j] 的最优解
- 转移：枚举分割点 k

## 📊 树形DP速查
- 遍历顺序：后序遍历 (DFS)
- 关键：子节点计算完后更新父节点
- 常见状态：选/不选、最大深度、最长路径
